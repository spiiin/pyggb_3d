# Python-driven GeoGebra

A webapp to allow people to interact with GeoGebra via Python.

[See it in action here.](https://www.geogebra.org/python/)

## Fork Information

This is a fork of the original Python-driven GeoGebra project with additional features and improvements:

### Features
- **3D geometry support** - Work with 3D objects, planes, and spatial mathematics

### Live Demo
- [3D GeoGebra Python Demo](https://spiiin.github.io/pyggb_3d/) - Interactive 3D mathematical environment
- [Tutorial](https://spiiin.github.io/blog/1496659028/) - GJK implementation
