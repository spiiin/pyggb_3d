Translate
=========

.. py:class:: Translate

   In the following constructor, additional keyword arguments can be
   provided to set properties of the new :py:class:`Translate`.

   .. py:method:: Translate(obj, vector)

      Construct the translation of the given *obj* (which can be a point, segment, polygon, etc.) by the given *vector*.

   A :py:class:`Translate` also has the following common properties:

   * :py:attr:`is_visible`
   * :py:attr:`color`
   * :py:attr:`color_floats`
   * :py:attr:`opacity`
   * :py:attr:`line_thickness`
