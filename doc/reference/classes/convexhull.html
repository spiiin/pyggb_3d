ConvexHull

class ConvexHull

In the following constructor, additional keyword arguments can be provided to set properties of the new ConvexHull.

ConvexHull(points)

Construct the convex hull of the given points, which should be an iterable of at least 3 Point instances. The convex hull is the smallest convex polygon that contains all the given points.

A ConvexHull also has the following common properties:

  • is_visible

  • color

  • color_floats

  • opacity

  • line_thickness
